ABOUT

你好，我是吃栗子不，目前做算法工程，主要方向是推荐系统。工作里接触得比较多的是排序、多任务学习、特征和评估；业余也会做一些 LLM、RAG 和 Agent 相关的实验。

我习惯把问题记下来。一个指标为什么涨、线上为什么没跟着涨、一次排查最后卡在哪里，这些细节过几个月很容易忘。这个博客主要存这些内容，也会放论文阅读和代码笔记。

最近在看

  • 推荐模型的离线提升，怎样稳定地转成线上收益。
  • LLM 和 Agent 怎样接进真实业务，而不是停在 Demo。
  • 评估、可观测性和工程约束，怎样跟上模型能力。
